# ICO Host — Railway Ready

لوحة ICO Host تعمل باستخدام Node.js بدون مكتبات npm خارجية.

## النشر على Railway

1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. في Railway اختر **New Project → Deploy from GitHub Repo**.
3. اترك أمر البناء الافتراضي، واجعل Start Command:

   ```bash
   npm start
   ```

4. من **Variables** أضف:
   - `ADMIN_PASSWORD`: كلمة مرور قوية خاصة بالأدمن (6 أحرف على الأقل).
   - `DATA_DIR`: `/data`

   لا تضبط `PORT` يدوياً؛ Railway يمرره تلقائياً إلى التطبيق.

5. من **Settings → Networking** أنشئ Public Domain. إذا طُلب Target Port فاستخدم قيمة `PORT` التي يخصصها Railway، ولا تضع رقماً ثابتاً مثل 8090.
6. أضف Volume واجعل Mount Path هو `/data` حتى تبقى بيانات الحسابات والملفات بعد إعادة النشر.

## التشغيل محلياً

```bash
ADMIN_PASSWORD='ضع-كلمة-مرور-قوية' npm start
```

## ملاحظات مهمة

- يجب أن تكون الصفحة الرئيسية في `public/index.html`؛ وقد تم وضعها في هذا المسار في هذه النسخة.
- التطبيق يستمع على `0.0.0.0` ويستخدم `process.env.PORT` تلقائياً.
- تحذيرات عدم وجود Python أو PHP أو Java أو unzip تعني أن أنواع البوتات التي تعتمد على هذه البرامج لن تعمل في بيئة التشغيل الحالية. واجهة Node.js يمكن أن تعمل رغم ذلك.
- تحذير أمني: تشغيل ملفات يرفعها المستخدمون على نفس حساب نظام التشغيل الخاص بالتطبيق ليس عزلاً آمناً. لا تفتح إنشاء وتشغيل ملفات المستخدمين للعامة قبل إضافة عزل حقيقي لكل عملية (مثل حاويات منفصلة مع حدود صلاحيات وموارد وشبكة).
