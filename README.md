# ICO Host

استضافة حقيقية للمواقع والبوتات والصور. Node.js بدون مكتبات خارجية.

## التشغيل
```bash
sudo apt install -y nodejs python3 php-cli default-jdk unzip
ADMIN_PASSWORD=',TAqjZ$*GZM.cs6' PORT=3000 node server.js
```
افتح `http://IP:3000`. الأدمن ليه كلمة مرور بس (من غير يوزر). كلمة المرور من `ADMIN_PASSWORD` وبتتطبق عند كل تشغيل. لو ماتحددتش، بتتطبع كلمة مؤقتة في الكونسل مرة واحدة عند أول تشغيل.

## البيانات
- `data/db.json` الحسابات والسيرفرات والإعدادات
- `data/servers/<id>/` ملفات كل سيرفر
- `data/images/` الصور المرفوعة

## تحذير أمني
الكود اللي بيرفعه المستخدمون بيتشغل بصلاحيات المستخدم اللي شغال عليه الخادم.
لا تفتحه للعامة من غير حاويات (Docker) أو مستخدم معزول لكل بوت.
